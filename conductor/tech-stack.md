# Tech Stack - Show Tracker

## Frontend
- **Framework**: Vue.js (via CDN or simple Vite setup)
- **Language**: JavaScript / HTML / CSS
- **Styling**: Standard CSS / Bootstrap (optional for layout)

## Backend / API
- **Runtime**: Python (Flask)
- **API Style**: RESTful API
- **External API**: TMDB API for movie/show data

## Database
- **Type**: SQLite (Simple, file-based relational database)
- **ORM**: SQLAlchemy (Standard for Flask)

## Deployment & Infrastructure
- **Hosting**: Local execution or simple Python hosting (PythonAnywhere/Heroku)
