# Product Definition - Show Tracker

## Vision
A tool that analyzes viewing history across platforms (starting with Netflix) to identify recurring actors, directors, and creators, using these insights to recommend new media.

## Core Features
- **Data Import**: Ingest viewing history from Netflix (CSV/JSON) and manual entry.
- **Media Lookup**: Connect titles to a database (TMDB) to fetch metadata (cast, crew, genres).
- **Cross-Reference Engine**: Find shared people across watched media.
- **Preference Scoring**: Weight recommendations based on frequency of shared talent and media types.
- **Search & Discovery**: Look up new shows/movies and see "match" scores based on personal history.

## User Personas
- **The Buff**: Someone who follows specific directors or actors across different genres.
- **The "What's Next?" User**: Someone looking for personalized recommendations based on past enjoyment.

## Future Goals
- Direct Netflix API integration (if possible).
- Support for other streaming services (Prime, Disney+, etc.).
